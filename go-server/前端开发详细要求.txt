核心指令
基于以下 API 文档逻辑和参考网站风格，精细化设计视频点播 + 直播平台的前端页面，要求布局、交互逻辑参考 https://www.stonelodgeacademy.com/，功能完全对齐 API 文档的接口能力，输出完整的页面设计方案（含视觉风格、页面结构、交互逻辑、UI 细节、功能模块映射）。
参考网站分析要求
参考 https://www.stonelodgeacademy.com/ 的核心特征：
布局风格：简洁大气的分层布局，侧边栏 / 顶部导航 + 主内容区的结构，响应式适配（桌面 / 平板 / 移动端）；
视觉风格：质感化设计，清晰的信息层级，简约但专业的配色体系，注重内容展示的沉浸感；
交互逻辑：流畅的筛选 / 切换动效，hover 反馈，加载状态提示，模块化的内容加载方式；
功能呈现：分类导航清晰，内容列表以网格 / 列表灵活切换，核心功能入口突出。
业务背景与 API 约束
设计的前端页面需完全对接「PlayerServer 视频点播 + 直播平台」API 文档（Go-PlayerServer 54567 端口为后端内部层，前端仅调用 Java Spring Boot 8080 端口接口），核心数据结构以文档中 MovieInfo、VideoListVO、VideoDetailVO 等为准，功能覆盖文档中所有前端可访问的接口能力。
精细化设计要求（分页面拆解）
1. 全局基础设计
配色体系：参考参考网站的低饱和度高级配色，主色调选深灰 / 藏蓝系（适配视频平台沉浸感），辅助色用橙色 / 青色（突出播放、收藏等交互按钮），中性色覆盖背景、文本、边框等层级；
字体体系：正文用无衬线字体（如 Inter、思源黑体），标题加粗且层级分明（H1-H6 对应页面标题 / 模块标题 / 内容标题）；
响应式适配：桌面端（≥1200px）、平板端（768-1199px）、移动端（<768px），不同尺寸下布局自动适配（如桌面端侧边栏 + 主内容，移动端折叠侧边栏为底部 / 顶部导航）；
全局组件：加载骨架屏（适配视频列表 / 详情加载）、全局弹窗（登录 / 注册）、面包屑导航（分类 / 播放页）、返回顶部按钮、全局搜索框（对接 /api/search 接口）。
2. 首页 / 发现页
布局结构（参考参考网站首页）：
顶部：导航栏（Logo + 核心入口：首页、分类、直播、个人中心）+ 全局搜索框（支持自动补全，对接 /api/movies/autocomplete 接口）+ 登录 / 注册入口；
首屏：全屏轮播图（展示热门视频，对接 /api/videos?sort=hot 接口的 top5 数据，显示封面、标题、评分）；
核心内容区：
「正在热映」横向滚动模块（对接 /api/videos?sort=score 接口，展示封面 + 标题 + 评分 + 备注）；
「最新上线」网格模块（5 列布局，对接 /api/videos?sort=time 接口，每页 40 条，显示 coverUrl、title、genre、score、remark）；
「分类速览」模块（对接 /api/category/tree 接口，展示一级分类 + 热门二级分类，点击跳转分类页）；
「直播推荐」模块（展示热门直播频道，对接 /api/cpp/live/groups 接口的 top3 频道）；
底部：版权信息、API 版本信息、隐私政策链接。
交互细节：
轮播图自动播放 + 手动切换，hover 时暂停；
视频卡片 hover 时显示评分、收藏 / 点赞按钮（未登录则提示登录），封面轻微放大；
分类速览项 hover 时高亮，点击后平滑跳转分类页并携带分类参数。
3. 分类浏览页
布局结构：
侧边栏：一级分类树（对接 /api/category/tree 接口，展示 9 个固定一级分类）+ 二级分类筛选（对接 /api/category/subs 接口，按选中一级分类加载二级分类）；
筛选栏（主内容区顶部）：类型筛选（电影 / 电视剧 / 综艺等，对接 /api/movies/types 接口）、年份筛选（下拉选择）、地区筛选（下拉选择）、排序筛选（score/time/hot，对接 /api/videos 的 sort 参数）、页码 / 每页条数切换；
内容区：视频网格（桌面端 5 列，平板端 3 列，移动端 2 列），对接 /api/videos 接口（携带 category/type/year/area/sort 参数），展示 VideoItemVO 结构的所有核心字段（封面、标题、评分、播放量、是否点赞 / 收藏）；
分页控件：底部分页，支持页码跳转、每页条数切换（10/20/40）。
交互细节：
筛选条件变更后无刷新加载内容（AJAX），加载时显示骨架屏；
筛选条件记忆（localStorage 保存，返回页面时恢复）；
视频卡片点击后跳转播放详情页，携带 vodId 参数。
4. 搜索结果页
布局结构：
顶部：搜索框（回显搜索关键词）+ 筛选栏（类型 / 年份 / 地区，同分类页）；
内容区：
自动补全提示（输入时对接 /api/movies/autocomplete 接口）；
搜索结果网格（同分类页），对接 /api/search 接口（携带 keyword/page/size 参数）；
无结果时显示空状态提示，支持重新搜索；
分页控件：同分类页。
交互细节：
搜索关键词输入时实时触发补全（延迟 500ms 防抖）；
搜索结果加载完成后高亮匹配的关键词；
支持回车 / 点击搜索按钮触发搜索。
5. 视频播放详情页
布局结构：
顶部：面包屑导航（首页 > 分类 > 视频标题）+ 操作栏（点赞 / 收藏 / 分享，对接 /api/videos/{videoId}/like、/api/videos/{videoId}/favorite 接口）；
主内容区：
左侧（70% 宽度）：HLS 播放器（对接 /api/videos/stream/{vodId} 接口，支持 m3u8 播放，HLS.js 实现）+ 播放控制栏（进度条、音量、倍速、全屏、线路切换）+ 选集列表（对接 VideoDetailVO 的 plays 字段，按 episode 展示，点击切换播放地址）；
右侧（30% 宽度）：视频信息卡片（标题、封面、年份 / 地区 / 分类、导演 / 演员、简介（含 HTML 解析）、评分、播放量、更新备注）；
底部：评论区（对接 /api/videos/{videoId}/comments 接口），支持分页加载、发表评论（需登录）、评论点赞。
交互细节：
播放器加载时显示加载动画，播放失败时提示切换线路；
选集列表过长时支持滚动，当前播放集数高亮；
播放进度实时上报（对接 /api/history/report 接口），返回页面时恢复进度（对接 /api/history/progress/{videoId} 接口）；
评论发表需登录，未登录时点击发表按钮弹出登录弹窗。
6. 直播页面
布局结构：
侧边栏：直播分组列表（对接 /api/cpp/live/groups 接口，如央视 / 卫视 / 地方台），分组可折叠 / 展开；
主内容区：
顶部：直播频道搜索框（按频道名筛选）；
频道列表（网格布局）：展示频道名称、封面（或 logo），hover 时显示播放按钮；
播放器区域：选中频道后加载 HLS 播放器（对接 /api/cpp/live/play 接口，获取重写后的 m3u8 地址）；
操作栏：播放器控制（音量、全屏、画质），频道切换快捷栏。
交互细节：
分组切换时无刷新加载对应频道列表；
播放器加载直播流时显示缓冲动画，断流时提示重试；
支持频道收藏（对接用户收藏接口），收藏的频道置顶显示。
7. 登录 / 注册页面（弹窗 / 独立页面）
布局结构：
登录表单：用户名 / 密码输入框、记住密码、登录按钮（对接 /api/auth/login 接口）、忘记密码（占位）、注册入口；
注册表单：用户名 / 密码 / 确认密码 / 昵称输入框、注册按钮（对接 /api/auth/register 接口）、登录入口；
样式：半透明背景层，表单卡片居中，输入框有焦点高亮、错误提示（如登录失败返回 message）。
交互细节：
表单验证（前端：密码长度、格式；后端：返回 code 非 200 时显示 message）；
登录成功后保存 token 到 localStorage，关闭弹窗并刷新页面（显示用户信息）；
支持刷新 token（对接 /api/auth/refresh 接口），token 过期时自动跳转登录。
8. 个人中心页面
布局结构：
侧边栏：个人资料、我的点赞、我的收藏、播放历史、退出登录；
主内容区（按选中项切换）：
个人资料：展示头像（对接 /api/user/avatar 接口）、用户名、昵称、注册时间，支持修改昵称（/api/user/profile PUT）、上传头像（/api/user/avatar POST）；
我的点赞：视频列表（对接 /api/user/likes 接口），支持取消点赞、删除；
我的收藏：视频列表（对接 /api/user/favorites 接口），支持取消收藏、删除；
播放历史：视频列表（对接 /api/history 接口），显示播放进度，支持删除单条记录、清空历史；
样式：卡片式布局，列表项显示封面、标题、进度 / 操作按钮。
交互细节：
头像上传支持预览，限制 2MB 大小；
操作（取消点赞 / 收藏、删除历史）后实时刷新列表，显示操作反馈；
未登录时访问个人中心自动跳转登录弹窗。
9. 管理面板（仅管理员角色可见）
布局结构：
侧边栏：服务器状态、采集管理、分类统计；
主内容区：
服务器状态：对接 /api/cpp/status 接口，展示 ServerSnapshot 所有字段（仪表盘、数值卡片、趋势图）；
采集管理：对接 /api/cpp/collect/status 接口，展示采集状态、进度、失败数，支持启动 / 重置采集（/api/cpp/collect/run、/api/cpp/collect/reset）；
分类统计：对接 /api/category/stats 接口，展示类型统计饼图、分类树（带数量）；
样式：数据可视化（ECharts）、操作按钮（禁用 / 启用状态根据采集状态切换）。
交互细节：
状态数据自动刷新（每 30 秒），支持手动刷新；
采集操作触发后显示加载状态，操作完成后提示结果；
分类统计图表支持下钻（点击分类查看二级分类数据）。
