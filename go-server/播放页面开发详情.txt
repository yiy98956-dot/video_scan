核心指令
生成一个完整可直接运行的 Vue3+TypeScript 单文件组件，1:1 复刻 B 站 2026 版视频播放页的所有功能与交互逻辑，彻底解决 "全屏后只有原生控制栏" 的核心问题，严格对接 PlayerServer 视频平台 API 文档（仅调用 Java 8080 端口接口，禁止直连 Go 54567 端口），所有功能必须能通过文档中的 API 实现，不添加任何额外功能。输出代码需带详细注释，每个 API 调用处标注对应接口路径。
技术栈强制要求
核心框架：Vue3 Composition API + TypeScript
播放器：HLS.js v1.5+（必须使用，支持 m3u8 流播放）
网络请求：Axios（统一封装请求拦截器，自动携带 Authorization 头）
工具库：dayjs（时间格式化）
样式：原生 CSS（使用 CSS 变量统一管理配色，不引入任何 UI 组件库）
全局核心约束（必须严格遵守）
绝对禁止使用浏览器原生 video controls 属性，所有播放控制功能必须完全自定义实现
全屏时必须全屏整个播放器容器（而非仅 video 元素），确保自定义控制栏、选集、线路切换在全屏状态下正常显示
所有视频播放地址必须通过/api/cpp/proxy?url={encodeURIComponent(原始地址)}代理
所有需要登录的接口（点赞 / 收藏 / 进度上报）必须先检查 token，未登录时提示登录
控制栏实现 "鼠标移动显示，3 秒无操作自动隐藏" 的逻辑
分模块功能详细要求
1. 播放器核心模块（最高优先级）
对应 API：/api/videos/{vodId}、/api/cpp/proxy、/api/history/report、/api/history/progress/{vodId}
播放器容器：16:9 固定比例，纯黑背景，无边框
自定义控制栏（底部悬浮半透明黑色）：
左侧：上一集按钮、播放 / 暂停按钮、时间显示（当前时间 / 总时长）
中间：进度条（包含缓冲进度条、已播放进度条，支持点击跳转，hover 显示时间戳）
右侧：音量控制（滑块 + 静音按钮）、倍速选择（0.5x/0.75x/1.0x/1.25x/1.5x/2.0x）、线路切换下拉框、选集按钮、全屏按钮
播放器逻辑：
进入页面自动调用/api/history/progress/{vodId}获取断点续播进度，加载完成后自动跳转
播放过程中每 30 秒自动调用/api/history/report上报进度，页面卸载前强制上报最后一次
支持 HLS 流播放，配置enableWorker: true、lowLatencyMode: true、maxBufferLength: 30
播放失败时显示 "播放失败，请尝试切换线路" 提示和切换按钮
支持键盘快捷键：空格（播放 / 暂停）、左右箭头（快进 / 快退 10 秒）、上下箭头（调节音量）、F（全屏）、M（静音）
自动隐藏逻辑：播放状态下，鼠标 3 秒无操作自动隐藏控制栏和顶部导航，鼠标移动时重新显示
2. 选集与线路切换模块
对应 API：/api/videos/{vodId}（返回的plays数组）
线路切换：显示 API 返回的所有PlayGroup.name（如 "线路 1"、"线路 2"），当前线路高亮
集数列表：网格布局，每行显示 8 个集数按钮，显示PlayUrl.episode（如 "第 01 集"）
当前播放的集数用橙色背景 + 白色文字高亮显示
点击集数自动切换播放地址，更新播放器
切换线路后默认播放当前集数（若该线路有对应集数），否则播放第 1 集
集数过多时添加垂直滚动条
3. 视频信息与互动模块
对应 API：/api/videos/{vodId}/like、/api/videos/{vodId}/favorite
视频标题：大号加粗字体，显示videoDetail.title
视频元数据：显示播放量、发布时间（dayjs(videoDetail.list_date).format('YYYY-MM-DD')）、评分、地区、年份
创作者信息：显示数据源名称、导演名
互动按钮组（B 站经典样式）：
点赞按钮：点击切换状态，数字实时更新，选中时橙色
收藏按钮：点击切换状态，数字实时更新，选中时黄色
分享按钮：点击弹出分享链接
视频简介：默认显示 3 行，超过部分折叠，显示 "展开" 按钮，过滤 HTML 标签
4. 右侧边栏模块
顶部标签页：简介、评论（评论功能可简化为占位，标注后续对接接口）
简介标签页：包含上述视频信息、互动按钮、选集模块
相关推荐模块：
标题 "相关推荐"
列表布局，每个推荐项包含封面图、标题、播放量
数据来源：GET /api/videos?category={videoDetail.genre.split(',')[0]}&sort=hot&size=15
点击推荐项跳转到对应播放页
5. 错误处理与边界情况
视频不存在：显示 "视频不存在或已被删除"，提供返回首页按钮
网络错误：显示 "网络连接失败，请检查网络后重试"，提供刷新按钮
未登录操作：点击点赞 / 收藏时弹出 "请先登录" 提示
播放线路全部失败：显示 "所有线路均无法播放，请稍后再试"
加载状态：视频加载时显示 B 站风格的三个跳动圆点加载动画
输出要求
输出完整的单文件 Vue 组件代码（.vue格式），包含<template>、<script setup lang="ts">、<style scoped>三部分
代码结构清晰，按模块拆分，添加必要的注释说明
每个 API 调用处标注对应的接口路径和参数
所有样式使用 CSS 变量定义，统一管理配色和尺寸
代码末尾添加 "开发部署说明"，包含：
依赖安装命令
API 基础地址配置
常见问题排查（如跨域、播放失败、全屏问题）
特别标注 "全屏功能实现关键点"，确保全屏后所有自定义功能正常显示
